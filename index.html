VaultMind: agentic security assistant

Powered by Groq (free tier). VaultMind plans, calls tools (knowledge-base search, passphrase generator, password strength check) and answers using retrieved docs. Your key stays in your browser's local storage and goes only to api.groq.com. Get a free key at console.groq.com.

Neural file inspector

Drop any file. A convolution layer (Sobel kernel, ReLU, max-pool) runs on its byte map in your browser, plus Shannon entropy. Encrypted or packed files look like uniform noise. The Docker backend runs a full PyTorch CNN on the same idea.

Architecture

Frontend

Static site on GitHub Pages. WebCrypto, WebAuthn-ready, in-browser RAG and agent loop.

API (FastAPI)

/chat with Groq tool-calling, /rag search, /scan CNN inference, rate limited.

RAG

Security knowledge base ranked by TF-IDF; swap in Qdrant or Chroma for embeddings.

CNN

PyTorch byte-image classifier flags encrypted, packed or anomalous files.

Docker

docker compose up runs API and web server with a non-root user and healthcheck.

Zero trust

Keys never leave the device; the server stores ciphertext and signed audit entries.
